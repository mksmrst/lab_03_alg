## Описание

В работе реализован алгоритм сортировки данных о продажах методом пузырьковой сортировки (Bubble Sort). Алгоритм принимает список числовых значений, последовательно сравнивает соседние элементы и при необходимости меняет их местами. Если текущий элемент меньше следующего, выполняется обмен значениями, что позволяет упорядочить данные по убыванию.

Для выполнения сортировки используются два вложенных цикла: внешний цикл отвечает за количество проходов по списку, а внутренний выполняет сравнение и перестановку элементов. После завершения работы алгоритма список оказывается отсортированным от наибольшего значения к наименьшему.

Сортировка реализована в функции `sort_sales_data()`. В основной части программы создаётся список значений продаж, вызывается функция сортировки и выводится результат работы на экран.
